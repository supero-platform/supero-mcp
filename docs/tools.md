# Tool reference

Every tool the Supero MCP server offers, generated from the live server's own
`tools/list` answer by [`scripts/gen_tools_reference.py`](../scripts/gen_tools_reference.py).
Do not edit this file by hand; re-run the script.

**64 tools.** Required arguments are in bold. Your agent reads the full
argument schemas itself when it connects; this page is the map for people.

| Family | Tools | What it is for |
|---|---|---|
| [`build_`](#build) | 33 | Author, validate, publish, deploy and test a whole application |
| [`schema_`](#schema) | 7 | List, validate, save and update object types |
| [`crud_`](#crud) | 5 | Read and write records of any type |
| [`rbac_`](#rbac) | 2 | Ask what the current credential may do |
| [`apikey_`](#apikey) | 1 | Scope summary for the key making the call |
| [`project_`](#project) | 1 | Link schemas into a project |
| [`sdk_`](#sdk) | 4 | Generate and download client SDKs |
| [`connector_`](#connector) | 11 | Drive external data sources: discovery, sync runs, connectivity tests |
